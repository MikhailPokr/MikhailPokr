## About me

My name is Mikhail Pokrovskii, I'm a game developer from Russia. I work with Unity and C#. I chose this path about 10 years ago. Since then, I keep learning and getting better.

## Current status

Now I'm learning Spanish in Barcelona. I want to find a school for game development, to keep learning and enter the industry. I have no commercial work experience, but I did some freelance work before.

## My journey

### Before 2020

* Simple console programs.

### 2020

* My first Unity game: Hirbirom-TKM. A simple platformer. I followed many tutorials.

### 2021

* A full console minesweeper game, and other console games.
* I started working as a junior programmer on the Terraria Minigames server. I wrote chat commands and worked with the server database. I worked there until August 2022.

### 2022

* Project S.A.W. — my first full Unity game. I made it as a university project. It has only one demo level.

### 2022–2023

* I started a game development course.
* MemorySFML — a classic memory game, made with a learning library called SFML.
* Strange Arcadoid-like — a simple, unusual Arkanoid-style game, also with SFML.
* MemoryGame — the same memory game idea, but in Unity.
* PlantsEnd — a game about growing plants, with selection and mutation.
* Minesweeper-Chain — my own project. A minesweeper game with a special "chain" mechanic for bombs.
* Rapax Fructus — I started this as an experiment in the Tower Defense genre (the course gave me the idea, but the task itself was not related). It became a multi-level Tower Defense roguelike. It has a good base, but it is not finished.
* Psyche of a gull — my first game jam. A platformer about a seagull.

### 2024

* Thanks to Alen, I started learning proper architecture, SOLID principles, and design patterns.

### 2025

* I started making Clowap. Later I rewrote it completely.
* PhysicalMatchThree — a test task for a job. I did not get the job. A match-3 game with physics.
* Mahjong — another test task. A classic mahjong solitaire game.
* ClockDoll — my second game jam. Good architecture, but we did not finish the game in time. The design was also too complex.

### 2026

* RadMaze — a small game made for someone who asked. A random maze where you look for bombs. I made it in 12 hours.
* Garden of Greed — a new version of PlantsEnd. More tools, better visuals.
* Alfar-Workshop — my third game jam. A game about combining cards and toys.

### Now working on

* Clowap — a new version, with cleaner architecture. Chess with RPG elements.
* A4M — a collection of 5 of my old games: Arcadoid, Memory, Minesweeper, MatchThree, and Mahjong.
